# ATS-PROJECT

**VintageATS — AI-Powered Resume & ATS Optimization Platform**

VintageATS is an AI-powered career optimization platform that helps job seekers analyze and improve their resumes for specific job roles.

Users can upload a resume PDF, select an industry and job role, and provide a job description. The application uses **Google Gemini AI** to extract resume information, analyze job requirements, compare both, and generate an ATS compatibility score along with matching skills, missing skills, strengths, and improvement suggestions.

It also includes an interactive **Resume Builder** that helps users create and preview professional resumes and export them as PDF.

### Key Features

* 📄 Resume PDF parsing and text extraction
* 🤖 AI-powered resume analysis using Gemini
* 🎯 ATS compatibility / match scoring
* 🔍 Resume vs. job description comparison
* 🧩 Matching and missing skill identification
* 💡 AI-generated resume improvement suggestions
* 🏢 Industry and job-role selection
* ✍️ Interactive resume builder
* ✨ AI-assisted resume content generation
* 📥 Professional resume PDF export
* 🎨 Responsive and modern web interface

### Tech Stack

**Frontend:** HTML, Tailwind CSS, JavaScript
**Backend:** Python, Flask
**AI:** Google Gemini API
**PDF Processing:** PyPDF2
**Deployment:** Gunicorn

VintageATS aims to make resume optimization smarter, faster, and more accessible by combining **Generative AI with traditional ATS-oriented resume analysis**.
